# Project Evidence

This folder contains photographs from the final FloodWatch prototype and its 2026 showcase.

The images are included as **implementation evidence** only. They do not replace the technical documentation in `/docs`.

## Evidence Index

| File | What it demonstrates |
|---|---|
| `floodwatch_prototype_full.jpg` | Complete physical prototype, controller enclosure, local LCD/buzzer/LED output, sensors, wiring and scaled flood environment |
| `water_level_sensor_closeup.jpg` | Analog water-level sensing hardware installed on the prototype |
| `rain_sensor_closeup.jpg` | Rain sensing plate used for rainfall detection |
| `dht22_and_rain_module.jpg` | DHT22 temperature/humidity sensor and rain-sensor interface module mounted on the model |
| `prototype_building_model.jpg` | Final prototype environment and sensor placement |
| `technovation_live_demo.jpg` | Live project presentation/demo during the university showcase |
| `technovation_award.jpg` | Showcase award evidence |

## Evidence policy

- These photographs show the real physical implementation and presentation environment.
- Cloud/Blynk screenshots are intentionally omitted from this evidence set because the retained screenshots span multiple development revisions and could create version ambiguity.
- Credentials, Blynk tokens and Wi-Fi secrets are excluded.
- The close-up showcase poster and general venue photograph are intentionally not included in the public repository because they add little technical evidence and the poster contains older project wording.
